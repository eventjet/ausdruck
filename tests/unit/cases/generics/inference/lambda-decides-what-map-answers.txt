nums:list<int>.map(|n| n:int > 2)
-- Input --
{ nums: [1, 2, 3] }
-- Expression type --
list<bool>
-- Output --
[false, false, true]
-- Note --
map is fn<T, U>(list<T>, fn(T) -> U) -> list<U>: the receiver decides T and the lambda decides U, so the call is typed
without an inline return type to say so.
