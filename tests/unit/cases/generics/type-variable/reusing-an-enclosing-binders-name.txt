-- Expression type --
fn<T>(fn<T>(T) -> T) -> T
-- Note --
The inner fn<T> owns a binder of its own, so it is a fresh, self-contained signature -- opaque to the one enclosing
it, the same way two unrelated signatures are (see
function-type/its-own-binder-survives-nesting-in-a-functions-parameter). Reusing the name T there doesn't shadow the
outer T: it names a variable the outer signature never sees, so the source resolves and prints back exactly as
written.
