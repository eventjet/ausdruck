-- Type error --

-- Note --
A written binder is stored as written (see printed-in-the-order-declared-not-the-order-first-used.txt), but that
doesn't mean any name written into it is accepted unchecked: TypeResolution::resolveSignature() separately walks the
parameters and the return type to see which variables they actually reach, and rejects a written name that walk
doesn't find, so a written name still has to earn its place. T is checked, and rejected, before U ever gets a turn --
the first of the two unused names is the one reported.
